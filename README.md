# 🐋 WhaleRadarCryptoBot

Бот для отслеживания крупных криптовалютных переводов (Whale Tracking Bot).

WhaleRadar анализирует большие транзакции в сети Ethereum и отправляет уведомления в Telegram, когда происходит движение больших объёмов токенов.

## 🚀 Возможности

✅ Отслеживание крупных переводов криптовалют  
✅ Уведомления в Telegram в реальном времени  
✅ Анализ токенов ERC-20  
✅ Определение направления движения средств:
- кошелёк → кошелёк
- кошелёк → биржа (возможная продажа)
- биржа → кошелёк (возможное накопление)

✅ Получение актуальной стоимости транзакции в USD  
✅ Определение уровня кита (Whale Level)

## 🪙 Отслеживаемые токены

- USDT
- USDC
- DAI
- LINK
- UNI
- AAVE
- SHIB
- PEPE
- DEXE

## 🛠 Требования

- Python 3.14+
- Telegram Bot
- Etherscan API Key
